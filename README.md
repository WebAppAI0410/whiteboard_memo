# WhiteboardMemo

WhiteboardMemoは、iOS と Android の両方で動作するクロスプラットフォームアプリです。ホワイトボードをそのままスマホに持ち込むメモ帳として設計されています。

## 機能

- 複数のボードを作成・管理
- 付箋の追加（通常型と正方形型）
  - テキスト編集
  - 色の変更
  - ドラッグで移動
  - ピンチで拡大・縮小
  - 影付きデザイン
- 画像の追加
  - ギャラリーからの読み込み
  - カメラからの撮影
  - 移動・回転・リサイズ
- 描画ツール
  - フリーハンド描画
  - 直線描画
  - 図形描画（四角形、円）
  - 色と太さの変更
  - 消しゴム機能
  - Undo/Redo機能
- ボード間のコンテンツコピー
- PNG画像としてエクスポート・共有
- ダークモード対応
- オフライン動作（ローカルストレージ）
- 有料プラン機能

## 技術スタック

- **フレームワーク**: Flutter
- **状態管理**: Riverpod
- **ローカルストレージ**: Hive (NoSQL)
- **画像処理**: image_picker, image_gallery_saver
- **共有機能**: share_plus

## ディレクトリ構成

```
lib/
├── constants/      # 定数、テーマ設定
├── models/         # データモデル
├── providers/      # Riverpodプロバイダー
├── screens/        # 画面
├── services/       # サービス（ストレージ、エクスポート）
├── utils/          # ユーティリティ関数
├── widgets/        # 再利用可能なウィジェット
└── main.dart       # アプリケーションのエントリーポイント
```

## 主要なクラス設計

### モデル

- **Board**: ボード情報を管理（付箋、描画、画像を含む）
- **StickyNote**: 付箋のデータモデル（テキスト、色、位置、サイズなど）
- **Drawing**: 描画データモデル（点の配列、色、線の太さなど）
- **ImageItem**: 画像データモデル（パス、位置、サイズなど）

### プロバイダー

- **BoardProvider**: ボードの作成、更新、削除を管理
- **DrawingProvider**: 描画ツール、色、線の太さ、履歴を管理
- **PremiumProvider**: 有料機能の管理

### サービス

- **StorageService**: Hiveを使用したデータの永続化
- **ExportService**: ボードのPNG出力と共有機能

## セットアップ手順

1. Flutterをインストール
2. リポジトリをクローン
3. 依存関係をインストール: `flutter pub get`
4. Hiveアダプターを生成: `flutter pub run build_runner build --delete-conflicting-outputs`
5. アプリを実行: `flutter run`
